**A researcher who builds the tools my research needs, with AI as my pair programmer.**

I work with qualitative data: interviews, transcripts, and the slow work of making sense of them. ### How I build

1. **Start from a real problem.** Usually my own, or my team's.
2. **Write the spec first.** User stories, priorities and what "done" means.
3. **Build with AI.** I use Claude Code and Lovable as pair programmers, and I own the product, architecture and security decisions.
4. **Test like it matters.** Automated tests and CI, plus a real run with real users before I call it shipped.
5. **Ship one link.** If people need an install or an account to try it, it isn't finished.
